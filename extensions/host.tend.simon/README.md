# Simon Odyssey: Neural Pulse

A modern Simon-style brain-training arcade game for tend.host.

## Highlights

- 60-session Neural Pulse training campaign across six circuits
- Classic Flow, Reverse Recall, and timed Focus Pulse modes
- Encore, Focus Shield, and Calm Tempo perks
- Adaptive playback speed and response timing
- Advanced sessions reposition pads to train flexible recall
- Persistent stars, personal records, session progression, ranks, and daily challenges
- Five-star mastery based on accuracy, speed, consistency, and independence
- Keyboard, mouse, touch, fixed-panel, desktop fullscreen, and mobile fullscreen support
- tend.host Runtime API 1 lifecycle and timer integration
