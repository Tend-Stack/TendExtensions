# Snake Odyssey: Neon Wilds

A modern tend.host Runtime API 1 rebuild of Snake with two main progression paths.

## Classic Growth

- Default endless Snake experience: eat, grow longer, and survive until collision.
- Speed increases automatically as the snake gains length.
- Rotating run challenges for length, food chains, score, golden food, power use, and phase gates.
- Immediate challenge rewards add score and Wild Charge during the run.
- Length milestones every five segments grant escalating score and charge bonuses.
- Persistent Classic records: best length, best score, completed challenges, current streak, and best streak.
- Daily Arcade challenge support for completing Classic objectives.
- Early runs remain close to traditional Snake; advanced Classic tiers gradually introduce gates, pulse barriers, sentries, obstacles, and echo cells.

## Expedition Missions

- 60 designed missions across six evolving worlds.
- Food, shard, gate, and chain objectives.
- Five-star ratings based on efficiency, mastery, skill, and clean routing.
- Predator Run remains available as a faster advanced variant.

## Shared systems

- Phase Skin, Charge Seed, and Time Weaver perks.
- Phase gates, pulsing barriers, moving sentries, and fragile echo cells.
- Normal, golden, and rush food.
- Wild Charge abilities: Phase, Overdrive, and Freeze.
- Persistent ranks, rewards, achievements, daily challenges, and records.
- Keyboard, WASD, swipe, and mobile directional-pad controls.
- Gameplay keys are isolated from tend.host workspace navigation.
- Container-aware fixed panel, desktop fullscreen, and mobile fullscreen layouts.
- Rich Web Audio feedback for movement, food, chains, gates, powers, milestones, challenges, completion, and collisions.
