# Synthwave theme pack

Gold contrails over a neon wireframe horizon.

A Tend theme pack: a declarative `theme` block in `extension.json` plus a wallpaper and a
thumbnail. It contains no code and asks for no permissions. Enable it in **Settings -> Extensions**,
then pick **Synthwave** in the wallpaper picker. Each account chooses its own theme and can tune it.

| File | Purpose |
|---|---|
| `wallpaper.webp` | The wallpaper photo (2000 px wide) |
| `thumb.webp` | Picker tile and store card (480 px wide) |

Build rules and the full manifest reference: [docs/themes.md](../../docs/themes.md).
